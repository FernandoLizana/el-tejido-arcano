# Guía de usuario

## Qué es

Un laboratorio para explorar **relaciones posibles** entre cartas según colores, símbolos, texto y estructura de red.

## Qué no es

No es un oráculo infalible, diagnóstico ni predicción del futuro.

## Flujo sugerido

1. Abrir UI Streamlit.
2. Elegir perfil (visual / psicológico / …) y capa.
3. Explorar comunidades en el grafo.
4. Comparar dos cartas y leer la explicación.
5. Analizar una tirada de tres cartas (puente, tensión, hipótesis).

## Interpretación segura

Prefiere: “podría sugerir”, “una hipótesis posible”, “dentro de este modelo”.  
Evita: certezas, fatalismo, consejos médicos/legales/financieros.
